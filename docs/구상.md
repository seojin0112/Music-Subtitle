# 구상 (스크래치패드)

> 확정된 초기 설계 결정은 [결정기록.md](결정기록.md)로 이관됨. (26.08.10)

## 미정 / 향후 아이디어

? **로그인 + DB** — 지금은 localStorage. 다른 기기에서도 보거나 남에게 공유하고 싶어지면
  Supabase 같은 백엔드 도입 검토. 그 시점에 데이터 마이그레이션은 JSON 백업으로 가능.
? **유튜브 자막 트랙 자동 싱크** — 영상에 타임코드 있는 자막이 달려 있으면 가져와서
  초안 싱크를 자동으로 채우고, 싱크 편집기로 보정하는 하이브리드.
? **나무위키 외 가사 소스** — 파서에 "구분 방식" 선택지가 이미 있으므로 소스별 프리셋
  추가로 확장 가능.
? **GitHub Pages 공개 배포** — 코드·데이터 로드 구조는 준비 완료(README 참고).
  개인 PC 저장으로 충분할지 지켜본 뒤 결정. 공개 시 가사 저작권 유의.
? **Data API 키 선택 입력** — 200곡 초과 플레이리스트, 프록시 없는 제목 조회가 필요해지면.
