# 설계 결정 기록

코드만 봐서는 복원할 수 없는 결정·기각 대안만 기록한다.

## 26.08.10 초기 구현

- **정적 사이트 + localStorage로 시작 (로그인·DB 없음)** — 핵심 기능(플레이리스트,
  자막 싱크, 클릭 이동) 검증이 우선. 로그인/DB는 추후 필요 시 도입.
- **플레이리스트 목록을 IFrame Player API의 `getPlaylist()`로 조회** — YouTube Data
  API v3 대신 선택. API 키 발급 없이 동작하는 것이 장점, 한 번에 최대 200개·재생목록
  제목 조회 불가가 한계. 제목은 noembed.com(oEmbed 프록시)과 재생 시
  `getVideoData()`로 보충.
- **❌ [기각] 나무위키 자동 스크래핑** — 공식 API 없음, Cloudflare 차단, 약관 금지.
  대신 가사 복사·붙여넣기 + 자동 파싱(원문/발음/해석 분리) 방식 채택.
- **타임스탬프는 내장 싱크 편집기로 제작** — 나무위키에는 시간 정보가 없음. 영상을
  재생하며 줄 시작마다 Space로 기록하는 방식. 유튜브 자막 트랙 자동 매칭은 추후 보조
  수단으로 검토 가능.
- **"프리미엄 전용 영상" = 유튜브 멤버십 영상 대응** — 사이트 로그인으로는 해결
  불가(시청자 본인의 유튜브 계정 멤버십 필요, 임베드 자체가 차단되는 경우 많음).
  재생 오류 감지 → "재생 제한" 배지 + 유튜브 링크로 대응.
- **네이티브 confirm()/prompt() 미사용** — 삭제류 버튼은 2단계 클릭 확인(armButton).
  브라우저 자동화·테스트를 막지 않고 UI 일관성 유지.
