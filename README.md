# Music Subtitle

유튜브 플레이리스트를 불러와 노래별 자막(원문·발음·해석)을 보면서 재생하는 사이트.
자막 줄을 클릭하면 해당 시점으로 영상이 이동한다.

빌드 도구·의존성 없는 순수 HTML/CSS/JS 정적 사이트.

## 데이터 저장과 공유

- 데이터는 브라우저 localStorage에 저장된다 (그 브라우저에서만 보임).
- 헤더 [전체 내보내기] → `data.json` 파일. [가져오기(추가)]는 기존 데이터에 병합
  (영상이 겹치면 가사가 있는 쪽을 유지), [가져오기(교체)]는 전체 교체.
- 플레이리스트 화면의 [내보내기]는 그 목록만 담은 JSON을 만든다 — 목록 단위 공유용.
- 저장소에 `data/data.json`이 있으면 localStorage가 빈 브라우저는 이 파일을 자동으로
  읽는다(열람용). 무언가 편집하는 순간부터 그 브라우저만의 로컬 사본이 생긴다.

### 사이트를 링크로 공유하려면 (선택, 미적용)

1. [전체 내보내기]로 받은 `data.json`을 `data/data.json`에 덮어쓰고 커밋·푸시
2. GitHub 저장소 설정에서 Pages를 main 브랜치 루트로 활성화
3. 발급된 주소를 공유 — 방문자는 저장된 데이터를 읽기 전용으로 본다

## 실행

```
python -m http.server 8000
```

저장소 루트에서 실행 후 http://localhost:8000 접속. (유튜브 플레이어는 `file://`에서
동작이 불안정하므로 로컬 서버 필요)

## 사용 흐름

1. 홈에서 유튜브 플레이리스트 URL(또는 영상 URL) 추가 → 영상 목록 표시
2. 영상 클릭 → **가사 입력** 탭에 나무위키 가사 복사·붙여넣기 → 자동 파싱 확인 후 저장
3. **싱크** 탭에서 영상을 재생하며 각 줄 시작 순간에 Space로 타임스탬프 기록
4. **자막** 탭에서 재생 — 현재 줄 자동 강조·스크롤, 줄 클릭 시 해당 시점으로 이동

멤버 전용 등 임베드가 막힌 영상은 "재생 제한" 배지가 붙고 유튜브 링크로 연결된다.
